作业 1¶

考虑一个简单的蛋白质合成与降解系统。蛋白质 $\text{P}$ 以恒定速率 $k_\mathrm{s}$ 合成，但其降解过程由一种蛋白酶催化，遵循米氏动力学： $$\frac{\mathrm{d}P}{\mathrm{d}t} = k_\mathrm{s} - \frac{V_{\max} \cdot P}{K_\mathrm{m} + P}$$

  1. 稳态解析：求出系统达到稳态时蛋白质浓度 $P^*$ 的代数表达式。

【解】 达到稳态，即 $\frac{\mathrm{d}P}{\mathrm{d}t} = 0$，解得 $P^* = \boxed{\frac{k_\mathrm{s}\cdot K_\mathrm{m}}{V_{\max}-k_\mathrm{s}}}$.

  1. 存在性分析：讨论在什么条件下（$k_\mathrm{s}$ 与 $V_{\max}$ 的关系），该系统能维持一个正值的稳定稳态？如果 $k_\mathrm{s} > V_{\max}$，浓度会发生什么变化？

【解】 显然当且仅当 $k_\mathrm{s} < V_{\max}$ 时，存在有限正值 $P^*$，即只有此时才存在正值稳态；而 $P < P^*$ 时 $\frac{\mathrm{d}P}{\mathrm{d}t} > 0$ 即 $P$ 在增大， $P > P^*$ 时 $\frac{\mathrm{d}P}{\mathrm{d}t} < 0$ 即 $P$ 在减小，故知该稳态是稳定的。综上，该系统能维持一个正值的稳定稳态，当且仅当 $k_\mathrm{s} < V_{\max}$。

如果 $k_\mathrm{s} > V_{\max}$，则 $\frac{\mathrm{d}P}{\mathrm{d}t}$ 恒正，浓度将一直增加。

  1. 参数影响：若增加合成速率 $k_\mathrm{s}$，稳态浓度 $P^*$ 是线性增加还是非线性增加？

【解】 $P^* = \frac{k_\mathrm{s}\cdot K_\mathrm{m}}{V_{\max}-k_\mathrm{s}} = \frac{K_\mathrm{m}}{\frac{V_{\max}}{k_\mathrm{s}} - 1}$，显然随 $k_\mathrm{s}$ 增加，稳态浓度是非线性增加。

# G 函数
def G(u: np.ndarray, v: float, J: float, K: float) -> np.ndarray:
    t1 = v - u
    t2 = u * K
    t3 = t1 + t2 + v * J
    return (t2 * 2) / (t3 + np.sqrt(t3 * t3 - 4 * t1 * t2))

def G_single(u: float, v:float, J: float, K: float) -> float:
    t1 = v - u
    t2 = u * K
    t3 = t1 + t2 + v * J
    return (t2 * 2) / (t3 + math.sqrt(t3 * t3 - 4 * t1 * t2))

# 单点求 v_gen 值
def v_gen(x: float, S: float) -> float:
    return k_0 * G_single(x * k_3, k_4, J_3, J_4) + k_1 * S

from scipy.integrate import solve_ivp

# 随机引擎
rng = np.random.default_rng()

# 加上异常（来自不合理随机数值）捕获的 G 函数
def G_safe(u: np.ndarray, v:float, J: float, K: float) -> np.ndarray | None:
    try:
        t1 = v - u
        t2 = u * K
        t3 = t1 + t2 + v * J
        return (t2 * 2) / (t3 + np.sqrt(t3 * t3 - 4 * t1 * t2))
    except:
        print('!: u = {0}, v = {1}, J = {2}, K = {3}'.format(
            u, v, J, K))

# ODE 初始化
def dRdt(t, R):
    return k_0 * G_safe(k_3 * R, k_4, J_3, J_4) + k_1 * S - k_2 * R

t_span = (0, 30)
t_eval = np.linspace(0, 30, 10000)

# 随机生成 5 组初始条件，数值积分并绘制轨迹
for i in range(5):
    k_0, k_1, k_2, k_3, k_4, J_3, J_4, S, R_0 = rng.random(9) * np.array(
        [1, 0.1, 2, 2, 1, 0.2, 0.2, 10, 1])
    sol = solve_ivp(dRdt, t_span=t_span, t_eval=t_eval, y0=[R_0])
    label = f'第 ${i+1}$ 组：$R_0={R_0:.2f},\\ S={S:.2f},\\ k_0={k_0:.2f},\\ \
              k_1={k_1:.2f},\\ k_2={k_2:.2f},\\ k_3={k_3:.2f},\\ \
              k_4={k_4:.2f},\\ J_3={J_3:.2f},\\ J_4={J_4:.2f}$'
    plt.plot(sol.t, sol.y[0], label=label)

# 图参数设置

  1. 用恰当文字解释体系的不可逆性。

【解】 从 1 题“$R$ 稳态（$R^*$）随 $S$ 变化”图中可见：当初始 $R$ 在低支时，随 $S$ 增加，$R$ 将沿低支向右移动，直到达到低支消失点（鞍结分叉点）时突跃到高支，并继续沿高支向右运动；而接下来随 $S$ 减少，$R$ 将一直沿高支向左运动，由于高支在 $S \ge 0$ 范围内始终为稳定稳态，故 $R$ 将永远不会再回到低支。故知，若初始 $R$ 在低支某处，只要 $S$ 增大到超过一定阈值（鞍结分叉点对应 $S$ 值）后再减小，则 $R$ 将永远不会再回到初始状态。此即体系不可逆性。
