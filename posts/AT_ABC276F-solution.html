AT_ABC276F Double Chance 题解

本文最近更新于 2025-07-12 23:58:39

题意

给定长为 NNN 的一列数 A1,A2,⋯ ,ANA_1, A_2, \cdots, A_NA1​,A2​,⋯,AN​。对于 K=1,2,⋯ ,NK = 1, 2, \cdots, NK=1,2,⋯,N，分别求出从前 KKK 个数里先后两次等概率随机取出一数并放回，两数较大值的期望。

题解

由题目描述和期望的定义知，对于一个固定的 KKK，答案是 ∑i=1K∑j=1Kmax⁡(Ai,Aj)K2\dfrac{\sum_{i=1}^K\sum_{j=1}^K\max(A_i,A_j)}{K^2}K2∑i=1K​∑j=1K​max(Ai​,Aj​)​。

K=1K = 1K=1 时答案显然是 A1A_1A1​。接下来，考虑增量计算答案。

分母的处理是平凡的。考察分子。

当 K=K0K = K_0K=K0​ 的结果已计算，现在令 K=K0+1K = K_0 + 1K=K0​+1，并加入 AK0+1A_{K_0 + 1}AK0​+1​ 时，分子增加了以下三个部分：

  • 对于所有先前加入的 Ai≤AK0+1A_i \le A_{K_0 + 1}Ai​≤AK0​+1​，AK0+1A_{K_0 + 1}AK0​+1​ 都会作为较大值在 (i,K0+1)(i, K_0 + 1)(i,K0​+1) 和 (K0+1,i)(K_0 + 1, i)(K0​+1,i) 处各贡献 111 次；

  • AK0+1A_{K_0 + 1}AK0​+1​ 会在 (K0+1,K0+1)(K_0 + 1, K_0 + 1)(K0​+1,K0​+1) 处贡献 111 次；

  • 对于所有先前加入的 Ai>AK0+1A_i > A_{K_0 + 1}Ai​>AK0​+1​，AiA_iAi​ 都会作为较大值在 (i,K0+1)(i, K_0 + 1)(i,K0​+1) 和 (K0+1,i)(K_0 + 1, i)(K0​+1,i) 处各贡献 111 次。

第一种贡献需要知道先前加入的 Ai≤AK0+1A_i \le A_{K_0 + 1}Ai​≤AK0​+1​ 的 iii 的数目，第三种贡献需要知道先前加入的 Ai>AK0+1A_i > A_{K_0 + 1}Ai​>AK0​+1​ 的 AiA_iAi​ 的和。任写一种支持维护前后缀权值和的数据结构即可。
