P4139

题意简述

TTT 组询问，每次给定模数 ppp，对应求出 22⋯2 mod p\displaystyle 2^{2^{\cdots^2}}\bmod p22⋯2modp 的值。

解题笔记—搬运

前置芝士：扩展欧拉定理

ab≡{ab(b<φ(p))ab mod φ(p) + φ(p)(b≥φ(p))(modp)\displaystyle a^b \equiv \begin{cases}a^b & (b < \varphi( p )) \\\\ a^{b \bmod \varphi( p ) \ + \ \varphi( p )} & (b \geq \varphi( p ))\end{cases} \pmod pab≡⎩⎨⎧​ababmodφ(p) + φ(p)​(b<φ(p))(b≥φ(p))​(modp)

解

因为幂次是无穷的，所以首先必然会进入 b≥φ(p)b \geq \varphi( p )b≥φ(p) 分支。

考察指数。因为 ∀ p:1≤φ(p)<p\forall \ p:1 \leq \varphi( p ) < p∀ p:1≤φ(p)<p，所以模数必然会在有限次递归后缩小到 111。由此，一方面由于模数在不断缩小，b≥φ(p)b \geq \varphi( p )b≥φ(p) 必然始终成立；另一方面，易见模数为 222 或 111 时余数为 000，故我们设计其作为递归边界。
