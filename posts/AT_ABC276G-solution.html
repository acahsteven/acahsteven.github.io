AT_ABC276G Count Sequences 题解

本文最近更新于 2025-07-12 23:58:39

题意

给定 N,MN, MN,M，求有多少个长为 NNN 的非负整数数列 A=(a1,a2,⋯ ,aN)A = (a_1, a_2, \cdots, a_N)A=(a1​,a2​,⋯,aN​) 满足：

  • 单调不降；

  • aN≤Ma_N \le MaN​≤M；

  • 相邻两项对 333 不同余。

题解

感觉比较有意思和巧妙的一道题。学习自 官方题解。


首先，将 AAA 差分得到 B=(a1,a2−a1,a3−a2,⋯ ,aN−aN−1)B = (a_1, a_2-a_1, a_3-a_2,\cdots, a_N-a_{N-1})B=(a1​,a2​−a1​,a3​−a2​,⋯,aN​−aN−1​)。AAA 与 BBB 构成双射，故对合法的 BBB 计数，即可知合法的 AAA 的数目。

因为 AAA 单调不降且相邻两项对 333 不同余，所以 BBB 为非负整数数列，且从第 222 项开始模 333 余 111 或余 222。又因为 aN≤Ma_N \le MaN​≤M，所以 ∑b≤M\sum b \le M∑b≤M。

问题即转化为求从第二项开始每项模 333 余 111 或余 222，且和不超过 MMM 的非负整数数列的数目。

将 BBB 的每一项写成带余除法的形式：bi=3ki+rib_i = 3k_i + r_ibi​=3ki​+ri​，这里 1≤i≤N, ki∈N, ri∈{0,1,2}1 \le i \le N,\ k_i \in \mathbb N,\ r_i \in \{0, 1, 2\}1≤i≤N, ki​∈N, ri​∈{0,1,2}。并记 K=(k1,k2,⋯ ,kN), R=(r1,r2,⋯ ,rN)K = (k_1, k_2, \cdots, k_N),\ R = (r_1, r_2, \cdots, r_N)K=(k1​,k2​,⋯,kN​), R=(r1​,r2​,⋯,rN​)。

考察一个特定的 RRR，则合法的 KKK 的数目，即为满足长度为 NNN 且和不超过 ⌊M−∑r3⌋\left\lfloor\frac{M - \sum r}{3}\right\rfloor⌊3M−∑r​⌋ 的非负整数数列的数目。求满足长度为 NNN 且和等于 SSS 的非负整数数列数目是经典问题，由隔板法可知答案是 (S+N−1N−1)\binom{S + N - 1}{N - 1}(N−1S+N−1​)。对其做前缀和，即得满足长度为 NNN 且和不超过一给定值的非负整数数列数目。

由上面可知，RRR 对 KKK 的影响只来源于 ∑r\sum r∑r。枚举 r1r_1r1​，枚举 r2∼rNr_2 \sim r_Nr2​∼rN​ 中取值为 111 的个数 ccc，容易求出具体排列的方案数 (N−1c)\binom{N - 1}{c}(cN−1​)，同时容易求出 ∑r=r1+2N−c−2\sum r = r_1 + 2N - c - 2∑r=r1​+2N−c−2，从而得到对应合法 KKK 的数目。由此可以求出答案。
